# ONLUYEN Auto Solver VIP (v4.0.0)

Công cụ tự động giải bài tập OnLuyen.vn với kiến trúc đa cổng AI, Dashboard điều khiển và khả năng tương tác chuẩn React/Vue.

## Cài đặt
1. Cài Tampermonkey.
2. Mở file `wrapper.user.js` trên GitHub → Raw → Cài đặt.

## Tính năng nổi bật
- **Dashboard điều khiển**: Giao diện nổi với các nút Start, Stop, Solve Once, Clear All, Skip.
- **Đa cổng AI**: Tự động fallback qua KeylessAI, Pollinations, Kilo Gateway, OVHcloud.
- **Hỗ trợ MathJax/LaTeX**: Trích xuất công thức chính xác.
- **Multimodal**: Gửi cả văn bản và hình ảnh cho AI.
- **Tương tác mạnh mẽ**: Giả lập sự kiện chuột và bàn phím để vượt qua React/Vue.
